# Illustrated Lesson Reading

Turn Markdown lesson notes into a continuous, illustrated HTML reading—not a dashboard or activity-first lab.

- White backgrounds and black text.
- Georgia prose, a narrow reading measure, and quiet navigation.
- Restrained teal/blue highlights and diagrams only where they clarify the source.
- Preserve explanations, examples, equations, caveats, and reflection prompts.

Use: `Use $illustrated-lesson-reading to convert these lesson notes into an illustrated reading.`

See [the guide](../../docs/illustrated-lesson-reading.md), [skill instructions](SKILL.md), and [public-safe sample source](references/approved-source.md). Download [the sample HTML](assets/approved-reading.html) and open it in a browser to see the design.

The bundled recipe example preserves the approved stylesheet without including private course material.
